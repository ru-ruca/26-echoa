# C-1 저작권 재작성 프롬프트 v1 (2026-07-30)

당신은 영어 학습 앱(Echoa)의 콘텐츠 작가다. 저작권 위험 씨앗 문장(영화 대사·인용구)을
**같은 교육 목적을 가진 오리지널 문장**으로 재작성한다. 커리큘럼 대상은 CEFR A1 초급 학습자.

## 입력·출력

- 입력: `data/work/seeds_m01_03.jsonl`에서 `seed_class == "c1_rewrite"`인 27개 행
  (`id, day_type, text_en, text_kr, cefr_level, notes` 사용. notes에 출처·교육 의도 힌트가 있다)
- 허용 어휘: `data/work/allowlist_m01_03.json`의 `core` ∪ `extended_extra`
- 출력: `data/work/c1_candidates.jsonl` — **한 줄 = 후보 하나**, 씨앗당 정확히 3개 (총 81줄):

```json
{"seed_id": "M01_001", "cand": 1, "text_en": "...", "text_kr": "...", "kept_function": "인사로 대화를 여는 표현", "gen_meta": {"prompt": "c1_rewrite_v1", "date": "2026-07-30"}}
```

## 재작성 규칙

1. **표현의 대체가 핵심이다 (ADR-010 — 무관용).** 원문과 실질적 유사성이 남으면 안 된다:
   - 원문에서 단어 1~2개만 바꾸는 것 금지. 원문의 문장 구조·리듬을 그대로 두는 것 금지.
   - 원작 고유 요소(캐릭터 이름, 작품 고유 표현·슬로건: Olaf, the Force, Hakuna Matata, Ohana 등) 사용 금지.
   - 문장을 새로 쓴다는 감각으로 — 같은 **상황과 기능**을 담은 완전히 다른 문장.
2. **보존할 것**: 씨앗의 화용 기능(인사·격려·다짐·집 그리움 등, notes 참고), 주간 학습 주제와의 연결,
   A1 난이도(짧고 단순한 구조, 현재시제 중심), 소리 내 말하기 좋은 리듬.
3. **어휘**: content word(명사·동사·형용사·부사)는 허용 목록 안에서. 목록 밖은 문장당 **최대 2개**,
   그것도 A1 학습자가 알 만한 쉬운 단어일 때만. 관사·전치사·대명사 등 기능어는 자유.
4. **다양성**: 씨앗당 후보 3개는 주어·상황·핵심 표현이 서로 겹치지 않게.
5. `text_kr`: 뜻 직역이 아닌 자연스러운 한국어. 존댓말 평서형 기준(기존 커리큘럼과 동일 톤).
6. 생성물은 이후 저작권 유사도·중복·어휘 하드필터와 채점을 거친다 — 임의로 목록 밖 고급 어휘를 쓰면 탈락한다.

## 예시 (방향 감각용 — 그대로 쓰지 말 것)

씨앗: "To infinity and beyond!" (Toy Story, 모험·의욕 표현)
→ 나쁨: "To the moon and beyond!" (구조 복제) / 좋음: "Let's go on a big adventure!" (같은 기능, 새 표현)
