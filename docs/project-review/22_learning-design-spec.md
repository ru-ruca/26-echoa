> **계승**: [19 일상 소통 중심 재설계](19_communication-first-redesign.md)(5축) · [15 학습 절차 명세](15_learning-flow-spec.md)(4단계 플로우 기준선)

## 1. 대상과 목표

**페르소나**(19번 계승): 단어 암기에 약하고 초급에서 영어를 포기한 적 있으며 **일상 소통이 목표**인 재도전 학습자(= 앱 소유자 본인). 하루 15~20분.

**설계 목표**: 읽기·듣기 이해 + SRS 암기 앱으로 이탈했던 것을 **"발화 중심 일상 회화"로 되돌린다.** 성공 기준은 "4년 뒤 C1"이 아니라 "6주 뒤 여행에서 말이 나온다".

**핵심 원칙 4가지**:
1. **발화 우선** — 모든 문장은 최소 1회 소리 내어 말한다(쉐도잉).
2. **뜻 암기 0** — 단어카드 뜻 외우기 활동을 설계에서 배제. 콜로케이션 구·예문 맥락으로 대체.
3. **최소 마찰** — honor system(자기 판정), all-or-nothing 금지(최소 코스도 스트릭 인정). **학습 자체는 늘 무제한 무료**(포인트·광고로 학습을 막지 않는다, §6).
4. **확장 가능한 코어** — 지금은 말하기 중심이되, **하나의 문장/콘텐츠를 듣기·읽기·쓰기 등 다른 패턴으로 돌려쓸 수 있게** 설계한다(§7 확장성). "시스템보다 학습 패턴·콘텐츠가 우선" — 패턴·콘텐츠가 정해지면 시스템은 거기 맞춘다.

## 2. 학습 흐름 (4단계 유지 + 말하기 사다리 내장)

15번의 4단계 아코디언(배타적, 상태 보존)을 **뼈대로 유지**하되 각 단계에 발화를 내장한다.

```
Step 1 Sentence  → Step 2 Words → Step 3 Practice → Step 4 Complete
(듣기+쉐도잉)      (콜로케이션)     (인출+발화)       (Again/Good)
```

### Step 1 — Sentence (듣기 + 쉐도잉 = Tier 0)
- TTS 청취 → ① 스크립트 보며 따라 말하기 1~2회 → ② 뜻 확인 → ③ 스크립트 숨기고 2회. **honor system, 판정 없음**(정의적 여과 최소화). 4~6회 상한.
- 발음 가이드: IPA·강세·억양 커브 표시(긴 문장은 청크별). 19번의 죽은 `PronunciationGuide` 자산을 RN/웹 컴포넌트로 재구현.
- 마이크 불필요.

### Step 2 — Words (뜻 암기 0)
- 단어 → **콜로케이션 구 헤드라인**으로 제시("wake up — The Lion woke up"). 단어 단독 뜻 암기 카드 금지.
- 콜로케이션 퀴즈 1문항. 단어는 탭 시 사전으로.

### Step 3 — Practice (인출 + 발화)
- phase 사다리: `fill_blank` → `listening` → **`speaking`** → `summary`. 15번의 2phase를 speaking 포함 3phase로 확장(19번 축1).
- **speaking phase = 말하기 사다리의 Tier가 점진 상승하는 자리**:
  - Tier 1 녹음-자가비교: MediaRecorder(웹)/expo-audio(앱) 녹음 → 내 목소리 vs 원어민 A/B → 자기 판정. 저장·전송 없음.
  - Tier 2 STT 인식 확인(게이트 후): 녹음→서버 전사→내용어 매칭 ≥60~70% 통과(3회 후 자동 통과). "AI가 알아들었나" 프레이밍. [ADR-008](../../../26-SenTalk-en-study-app/docs/adr/008_speaking-practice-stt.md).
  - 마이크 불가 시 listening 폴백.

### Step 4 — Complete (FSRS 2버튼)
- Again/Good 2버튼(D-01). Practice 결과로 제안 자동 산정.
- `POST /api/progress` → FSRS 스케줄링 + XP + 스트릭.

## 3. 세션 구조 (15~20분 3부 + 최소 코스)

19번 축5. 홈의 "오늘의 플랜" 체크리스트로 제시.
1. **복습 워밍업 4~5분** — FSRS ~6장(1~2장 speaking).
2. **신규 8~10분** — 기존 문장 1 + 회화 페어 1~2(쉐도잉 포함).
3. **오늘의 소리내기 3~5분** — 오늘+어제+그제 문장 연속 쉐도잉(세션 내 회상만).

**최소 코스**: "복습 5분" 또는 "신규 1문장"만 해도 스트릭 인정 — 시간 부족 이탈 방지.

## 4. 콘텐츠 구조 (매일 회화 + 저작권 준수)

- 하루 = **기존 커리큘럼 문장 1개 + 관련 회화 페어 1~2개**(19번 축2). 회화 노출을 주 1일 → 매일로.
- **저작권**: 모든 공개 문장은 [ADR-010](../adr/010_content-copyright-and-data-model.md) 준수 — 저작권 free(자작·AI생성·AI재작성·PD)만. 위험 슬라이스(movie·drama·news·ted 등 341개=9.4%)는 **AI 재작성**으로 교체, 원문은 `content_originals`에 격리(공개 미노출).
- 문장마다 `content_origin` 필드로 출처 성격 기록(감사 가능).
- 커리큘럼 골격(month 1~48)은 불변, 스테이지 오버레이만 추가.

## 5. 동기 설계 (이정표 + 게이미피케이션)

- **커리큘럼 이정표**(19번 축3): "4년 뒤 C1" → **과업 기반 근접 목표**. S1(M01-02) 여행 생존 1 → S2 여행 생존 2 → S3 스몰토크 입문 → ... 홈 진행률을 "M01 Week2"가 아니라 **"여행 생존 1 — 8/20문장"**으로. `curriculum-stages.ts` 상수 1개.
- 졸업 과제: 초기 쉐도잉 self-check → STT 도입 후 "통과".
- 기존 게이미피케이션(XP·스트릭·배지) 계승. 단어 재등장 배지("아는 단어 3개")로 다중 맥락 재노출 가시화.

## 6. 수익 — 포인트·자발 광고·기부 이코노미 (무료 기반)

수익 = 무료+광고(D-23)이되, **강제 전면광고 대신 "자발적 광고 + 포인트 + 소액 기부"** 이코노미로 간다(조사 §5.1: 강제 전면 남발 시 D7 리텐션 10~30%↓, opt-in/보상형이 리텐션 친화적).

**철칙 — 학습은 막지 않는다**: 포인트·광고가 "오늘의 학습(신규+복습)"을 게이트하지 않는다. 듀오링고 "하트"식 학습 차단은 학습 앱 본질과 충돌·의욕 저하라 배제. 학습 자체는 항상 무제한 무료.

**포인트 이코노미**:
- 초기 포인트 지급 + **시간 경과 시 자동 재충전**(재방문 유인).
- 포인트는 **부가기능에만 소비** — 무제한 힌트, STT 재시도 추가, 별책부록(§7) 심화 열람, "광고 없는 시간" 구매 등. 학습 진행 자체엔 불필요.
- **자발적 광고**로 포인트 충전 — "학습이 좋으면 광고 봐서 후원" 프레이밍(강제 아님).

**소액 기부(개발자 커피값·서버비)**:
- 예: 1,000원 후원 → 1주일 무제한 포인트/광고 제거. "구독"이 아니라 **1회성 후원**.
- **정책 주의**: Vercel Hobby는 기부 요청도 상업으로 금지 → 광고와 함께 **Pro 필요**. 앱스토어는 "무제한 포인트 제공" 대가가 붙으면 IAP 대상(수수료) → **웹 결제(Stripe/토스 등)로 처리**해 스토어 수수료 회피(20 §5.3).

**광고 형식**: 레슨 완료 후 전면은 유지하되 **자발 시청(보상형) 우선**, 학습·쉐도잉·녹음 흐름 중엔 광고 0. 빈도 캡 세션당 1~2회.

**개인정보**: 광고ID·행태정보 처리방침 조항, iOS ATT 프롬프트([ADR-010](../adr/010_content-copyright-and-data-model.md)·[20 §5.2](20_release-feasibility.md)).

## 7. 학습 모드 확장성 (말하기 코어 → 4기능 트랙 + 별책 부록)

**지금은 말하기 중심**이되, 구조를 4기능(말하기·듣기·읽기·쓰기)으로 확장 가능하게 설계한다. 당장 다 만들지 않고, 코어(말하기)를 견고히 한 뒤 트랙을 붙인다.

**설계 원칙 — 엄격한 순서보다 "통합 + 리듬"**:
- 4기능 순서(사용자 사례: 말하기>듣기>읽기>쓰기)는 **소통 목표엔 합리적**(발화 인출이 기억 강화). 다만 언어습득 이론(크라센)은 이해가능한 입력(듣기·읽기) 우선도 지지 → **말하기 코어 + 듣기를 짝으로**(듣고→따라 말하기 = 이미 쉐도잉).
- "말하기 전부 끝나고 듣기"식 **단계 분리보다, 문장 하나를 여러 기능으로 돌려쓰는 통합**이 효율적(같은 콘텐츠 재활용).
- **주간 리듬**: 5일 신규 학습 + 2일 복습·선택 모드. 스테이지 진행에 따라 강조점 이동(초기 말하기 비중↑ → 후기 듣기·읽기·쓰기 비중↑).

**4기능 트랙(향후, 같은 콘텐츠 재활용)**:
| 트랙 | 지금 | 확장 |
|---|---|---|
| 말하기(코어) | 쉐도잉(Tier0)→녹음(Tier1)→STT(Tier2) | — |
| 듣기 | Practice의 listening phase | 받아쓰기(dictation), 무자막 듣기, 배속 |
| 읽기 | Sentence 스크립트 | 다독(문장군 모아 읽기), 별책 부록 |
| 쓰기 | fill_blank | 문장 재구성 → 자유 작문 |

**별책 부록(단어 중심 탐색)** — 사용자 제안:
- day 학습과 **별도 서브 세션**. 단어 선택 → 그 단어가 나온 **모든 학습 문장을 모아 보기·읽어보기·들어보기**(`sentence_words` 조인).
- 뜻 암기 0 원칙과 부합 — 뜻 카드가 아니라 **다중 맥락 재노출**(같은 단어를 여러 문장에서). 콜로케이션·예문도 함께.
- 포인트 심화 열람(§6) 대상 후보.

## 8. 콘텐츠 확장 백로그 (단계적 — 리스트업 후 각각 조사·적용)

콘텐츠가 학습의 핵심이므로, "저작권 교체"를 넘어 다양화까지 확장하되 **한 번에 48개월 일괄 금지**(19번). 각 항목은 조사(효과·저작권·규모) → 파일럿(M01~03) → 단계 적용.

| # | 항목 | 설명 | 우선 |
|---|---|---|---|
| C-1 | **저작권 위험 슬라이스 재작성** | 341개(9.4%)+news·ted·drama AI 재작성([ADR-010](../adr/010_content-copyright-and-data-model.md)) | 1순위(출시 전제) |
| C-2 | **패턴 기반 문장 확장** | 기존 문장의 문법·표현 패턴으로 변형 문장 생성(같은 표현 다른 맥락) | 조사 후 |
| C-3 | **대화 패턴 확장** | 문장에 대한 답글·이어지는 A-B 대화(말하기 목표에 맞는 턴) | 조사 후 |
| C-4 | **단어 예문·콜로케이션 다양화** | 예문 빈칸·콜로케이션 헤드라인 AI 보강(뜻암기0 대응) | 조사 후 |
| C-5 | **4기능 트랙용 콘텐츠 파생** | §7 트랙 확장 시 듣기·읽기·쓰기용 콘텐츠 파생 | §7 착수 시 |

원칙: C-1은 출시 전제라 먼저. C-2~C-5는 각각 별도 조사 문서로 리스트업 후 단계 적용(폭이 넓으므로).

## 9. UI/UX 화면 (와이어프레임 수준)

RN(앱)/웹 UI는 각각 구현하되(2벌), **흐름·상태 규칙은 `packages/core`로 공유**. 아래는 플랫폼 공통 정보 구조.

### 홈 — 오늘의 플랜
```
┌───────────────────────────────┐
│  여행 생존 1 — 8/20문장  🔥5일 │  ← 스테이지 진행률 + 스트릭
│  ─────────────────────────    │
│  오늘의 플랜 (15~20분)         │
│  ☐ 복습 워밍업 (6장)          │
│  ☐ 신규 — 오늘 문장 + 회화 2  │
│  ☐ 오늘의 소리내기 (3문장)    │
│  [오늘 학습 시작 ▶]           │
│  (최소 코스: 복습 5분만 해도 ✓)│
└───────────────────────────────┘
```

### 학습 — 4단계 아코디언 (배타적, 상태 보존)
- 15번의 아코디언 규칙(항상 1개만 열림, completed 리뷰, locked 잠금, Practice 상태 보존) 계승.
- Step 1에 쉐도잉 UI(따라말하기 카운터 + 발음 가이드), Step 3에 speaking phase(녹음/재생 or STT).

### 복습 — FSRS 큐
- 3타입(sentence/word/collocation) × 퀴즈 분기. 문장 reps≥2는 fill_blank/listening/speaking 3분기(마이크 불가 시 listening 폴백).

### 진도·통계
- 스테이지별 진행, 스트릭, 주간 리포트. 발화 횟수(쉐도잉·녹음) 가시화.

## 10. 데이터·기술 연계

- 학습 로직(FSRS·게이미피케이션·대화 window·리뷰 분기)은 `packages/core`(순수 TS, 웹/앱 공유). [21번](21_rebuild-plan.md).
- 스키마: 기존 sentences/vocabulary/sentence_words/sentence_ipa 계승 + `content_originals` 격리 테이블 + `content_origin` 필드([ADR-010](../adr/010_content-copyright-and-data-model.md)).
- 회화 배치: `/api/next-lesson` month/week/day 정렬(19번 — 데이터 INSERT만으로 동작).

## 11. 하지 말 것 (19번 계승)

발음 유사도 채점 알고리즘, Web Speech `SpeechRecognition`(iOS PWA 미동작), 마일스톤 DB 테이블, 48개월 일괄 증강, 요일별 해금 스케줄러, 적응형 커리큘럼 엔진, AI 프리토킹 봇 — 1인·15~20분 앱 ROI 초과. **학습 중 광고**(몰입 파괴)도 금지.

## 12. 미결정 / 후속

- **광고 SDK 선택**(AdMob) 및 배치 세부 A/B — 배포 후.
- speaking phase Tier 상승 시점(Tier1→Tier2 게이트: P1 실사용 2~4주).
- 스테이지 정의 세부(S3 이후 과업 목록) — 생존영어 8상황 기반 확정 필요.
