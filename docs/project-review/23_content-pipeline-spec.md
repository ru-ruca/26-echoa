## 1. 조사에서 얻은 설계 제약 (핵심 4가지)

이 spec의 모든 결정은 아래 실측·사례에서 나왔다.

1. **프롬프트만으로 CEFR 난이도 통제는 안 된다** — 여러 연구가 실측으로 확인. 실무 해법은 **overgenerate + 자동 채점 재랭킹**(N개 생성 → 스코어러로 최선만 채택). 파인튜닝 없이 1인이 쓸 수 있는 핵심 장치.
2. **어휘 통제는 wordlist 강제로** — 레벨별 허용 단어 목록을 프롬프트에 주입 + 사후 초과율 필터. Echoa는 자체 자산(단어 3,910·콜로케이션 5,705)으로 허용 목록 구성 가능.
3. **대화는 짧게(2~6턴)** — 턴이 길어지면 목표 난이도에서 이탈("alignment drift")하는 것이 실측됨.
4. **Duolingo식 3단계가 업계 검증 골격** — 사람이 설계 → 템플릿으로 대량 생성 → **노출 전 전량 검수**. 우리도 이 골격을 따른다.

**과생성 함정**: model collapse(반복·다양성 붕괴). 완화 = 다양성 강제 + 중복 제거 + **1세대만 생성**(생성물을 다시 씨앗으로 쓰지 않음) + 원본 혼합.

**저작권**: AI 순수 생성물 자체는 보호 대상이 아니라는 논의가 있으나, 진짜 리스크는 **씨앗 재작성 시 원문 유사도**다. 단어만 바꾸는 것은 면책이 되지 않는다([ADR-010](../adr/010_content-copyright-and-data-model.md)).

## 2. C-2 — 패턴 기반 문장 확장

**생성 방식: paraphrase가 아니라 substitution drill.**
씨앗 문장을 `고정부(문법 골격) + 슬롯`으로 분해하고, **슬롯만 허용 어휘로 치환**한다. "패턴은 유지, 내용은 새로" — 이 방식이 품질(패턴 학습 목적 유지)과 저작권(표현 대체) 둘 다에 안전하다.

```
씨앗:  "I usually wake up at 7 AM."
분해:  "I usually [VERB-PHRASE] at [TIME]."     ← 고정부 = 패턴
생성:  "I usually leave home at 8 AM."
       "I usually check my phone at noon."       ← 슬롯만 교체
```

**생성 규모**: 씨앗당 **5~8개 변형**. 주어·상황·시간대를 서로 다르게(diversity forcing) 지시 → CEFR·자연스러움 judge로 재랭킹 → 상위만 채택.

**씨앗 적격성 (2026-08-04 파일럿 실측 추가)**: C-2는 **일상 발화 문형에만** 적용한다. 계열별 judge 평균이
`real` 4.25 · `movie` 4.02 · `quote` 3.92 · `tale` 3.77 · **`proverb` 2.92**로 갈렸다. 속담·화석화 관용구·
고유명사 의존 문장·A1 초과 고정부·서사체 인용문은 슬롯 치환이 "지어낸 격언"을 만들거나 관용구 학습을 되레 막는다.
제외 규칙은 [style_lessons §13~17](../../tools/content-pipeline/prompts/style_lessons.md), 실측은
[05 리포트](../../tools/content-pipeline/reports/05_c2_pilot_metrics.md).

**프롬프트 전략**:
- 씨앗의 고정부(패턴)를 명시적으로 제시하고 "이 패턴을 유지하라"고 지시.
- 허용 어휘 목록(해당 month까지 학습한 단어 + CEFR 레벨 이하)을 주입, "목록 밖 단어 사용 금지".
- 변형끼리 주어·맥락이 겹치지 않게 명시(다양성 강제).
- 1세대만 — 생성 결과를 다시 씨앗으로 쓰지 않는다.

## 3. C-3 — 대화 패턴 확장

**생성 방식: 씨앗 문장을 학습자(B) 발화로 두고 앞뒤 턴을 붙인다.**

```
A: What time do you usually wake up?      ← 유도 턴(생성)
B: I usually wake up at 7 AM.             ← 씨앗 문장(고정)
A: That's early. Do you feel tired?       ← 이어짐(생성)
B: Sometimes, but I get used to it.       ← 이어짐(생성)
```

**규모**: 총 **4턴 안팎(2~6턴 상한)**. 조사의 "짧게" 제약을 그대로 적용 — 마지막 턴까지 난이도가 유지되는지 검증한다.

**프롬프트 전략**:
- "주고받는 대화를 이어가라(keep it going back and forth)" + 허용 어휘 이하만.
- 역할(A/B)과 상황을 명시. 씨앗 문장은 **그대로 유지**(B의 발화로 배치).
- overgenerate → 응집성·난이도 judge로 재랭킹.

**적재**: 기존 `day_type='conversation'` 스키마와 쉐도잉 자산(speaker·dialogue_title·순차 재생)에 그대로 들어가는지 검증 — 새 스키마를 만들지 않는다.
→ **2026-08-05 검증 완료**: 대화 50개 = 200행이 기존 스키마에 그대로 매핑(id·dialogue_id 충돌 0, 필수 필드 충족, 스키마 외 필드 0).
대화 번호는 101~로 발번해 기존 DLG_M01_001·002와 분리. [preview](../../tools/content-pipeline/output/c3_rows_preview.jsonl)

**씨앗 적격성 (2026-08-05 대조 실험)**: C-2 부적격 씨앗의 C-3 이관 가능성을 A군(일상발화 22) vs B군(C-2부적격 28)으로 검증했다.
**속담은 C-3로 살아나고(seed_fit 75%), 동화·서사체는 C-3에서도 살아나지 않는다(10%)** — 상황 설정이 낭독 프레임으로
도망가 학습자의 실제 발화가 되지 못한다. 규칙은 [style_lessons §18~19](../../tools/content-pipeline/prompts/style_lessons.md),
실측은 [08 리포트](../../tools/content-pipeline/reports/08_c3_pilot_metrics.md).
**마지막 턴 A1 유지는 50/50 달성** — 4턴 상한과 length_creep 게이트가 유효했다.

## 4. 검수 게이트 (2단 자동 + 인간 샘플)

노출 전 전량이 아래를 통과해야 한다.

**1단 하드 필터(자동, 통과/탈락)**
- 문법 오류
- 허용 어휘 초과율 초과
- **씨앗 유사도 초과**(저작권 — 표현 대체가 불충분한 것 탈락)
- 근접 중복(near-duplicate) — 생성물 간·기존 DB와
- 패턴 이탈(C-2: 고정부 훼손 / C-3: 턴 구조 붕괴)

**2단 LLM-as-judge(1~5점 채점 → 재랭킹)**
- 자연스러움 / CEFR 적합 / 패턴 유지(C-2) 또는 응집성·턴테이킹(C-3) / 교육적 가치

**3단 인간 검수**
- 무작위 **5~10% 전수 확인** + **judge 저점 전량 확인**. Duolingo도 노출 전 사람이 본다.

## 5. 파일럿 (M01~03 한정)

48개월 일괄 생성 금지([19번](19_communication-first-redesign.md)). **M01~03만** 먼저 돌려 기준 충족을 확인한 뒤 월 단위 확대.

**성공 기준(제안)**
| 지표 | 기준 |
|---|---|
| judge 평균 | ≥ 4/5 |
| 인간 검수 합격률 | ≥ 90% |
| 근접 중복률 | < 2% |
| 씨앗 유사도 초과 | **0건** (저작권 — 무관용) |
| C-3 마지막 턴 CEFR 유지 | 유지 |

기준 미달 시 프롬프트·필터를 고치고 재실행. 통과 후에만 확대.

## 6. 데이터 처리

- 생성 문장은 `content_origin='ai_generated'`(신규) 또는 `'ai_rewritten'`(씨앗 재작성)으로 기록([ADR-010](../adr/010_content-copyright-and-data-model.md)).
- 저작권 위험 씨앗을 재작성한 경우 **원문은 `content_originals`에 격리**(공개 API·git·CSV·백업 제외).
- 생성 메타(모델·프롬프트 버전·생성일)를 남겨 재현·감사 가능하게.

## 7. 실행 순서

| 단계 | 내용 |
|---|---|
| 1 | 허용 어휘 목록 구성(month별 누적 단어 + CEFR 필터) |
